# Library Management System

## Project Description
A simple menu-based Library Management System developed using Python to manage book records and track book availability.

## Technologies Used
- Python 3

## Features
- Add New Books
- View All Books
- Issue Books
- Return Books
- Check Book Availability
- Prevent Duplicate Book Entries
- Menu-Based Interface

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run `library_management.py`.
5. Select the required menu option.

## Project Objective
To simplify basic library operations and manage book information efficiently using Python.
